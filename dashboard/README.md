# Dashboard — rintu@kali

Hacker-style dashboard for the personal dev environment. Vite + React.

- `npm install` → `npm run dev` to develop
- `npm run build` → production build in `dist/`
- Pages: Overview (live monitors) · Tools (searchable library) · Terminal (emulated shell) · Docker (layers) · CI/CD · Snippets

Deployed via GitHub Pages (`static.yml`) and Vercel.
